# Introduction to Computer Science 
### NIBM | Diploma in Software Engineering 24.3 | CODSE24.3F-107

This repository contains my coursework for the Introduction to Computer Science (ICS) module.

#### 📌 Project Overview
The objective of this coursework is to analyze and propose optimal computer hardware configurations and IT infrastructure for a graphic design agency. It covers hardware specifications, networking, maintenance, and data security.

#### 🖥️ Key Topics Covered
**1. Desktop Computer Specification**
- Detailed breakdown of components: Casing, Intel i7 11th Gen Processor, Intel Q570 Chipset, 16GB DDR4 RAM (3200MHz), 512GB SSD, OS (Windows 11 Pro)
- Peripherals: USB Type-C, HDMI, RJ45, Display, Keyboard & Mouse

**2. Best Hardware Setups for a Graphic Agency**
- **Desktops:** Intel i7 10th Gen, high-performance setup for rendering & multitasking
- **Laptops:** 16GB DDR4, 15.6" Full HD IPS Display for creative work
- **Servers & Network Devices:** Routers, Switches, Wi-Fi Access Points, Firewalls for secure agency network

**3. System Maintenance & Security**
- PC maintenance best practices
- Security measures
- Data Backup Strategies: Incremental vs. Differential Backup (Pros & Cons)

#### 🛠️ Technologies / Concepts
`Computer Hardware` `Networking` `System Administration` `Data Backup` `IT Infrastructure`
